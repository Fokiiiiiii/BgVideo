# BgVideo

Minimal BetterDiscord plugin for animated video backgrounds.

BgVideo allows you to use a video as your Discord background, replacing the static background with a looping animated scene while keeping the interface fully usable.

## Features

- Play a looping video behind the Discord UI
- Lightweight implementation
- Supports common formats like `mp4` and `webm`
- Built-in settings UI for quick configuration

## Settings

The plugin includes a configuration panel inside BetterDiscord where you can:

- Set the video source
- Adjust playback options
- Control visual behavior of the background video

Open it via:

`Discord Settings → BetterDiscord → Plugins → BgVideo`
